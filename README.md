📊 Retail Sales & Profit Analysis
📌 Project Overview

This project focuses on analyzing a Retail Sales dataset to uncover valuable business insights and build an interactive Power BI dashboard. The project follows the complete Data Analytics workflow, including data cleaning, data transformation, SQL analysis, and dashboard creation.

🎯 Project Objective

The objective of this project is to:

Clean and preprocess retail sales data
Handle missing values and data quality issues
Perform business analysis using SQL
Generate actionable insights from sales data
Build an interactive Power BI dashboard for decision-making

Technology was the most profitable product category.
Corporate customers contributed the highest profit.
Top-performing products generated significant revenue.
October recorded the highest monthly sales while August showed the lowest sales performance.
